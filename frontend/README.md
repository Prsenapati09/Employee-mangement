# Frontend

Next.js App Router application with TypeScript, Tailwind CSS, and ESLint. Route pages and domain directories are setup placeholders; business functionality has not been implemented.

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_API_URL` if the backend URL differs from its local default.

Run `npm run dev`, `npm run build`, `npm run lint`, or `npm run typecheck` from this directory. Root scripts are also available from the repository root.
